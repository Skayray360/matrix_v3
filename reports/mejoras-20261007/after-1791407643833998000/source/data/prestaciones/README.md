# Documentos de prestaciones

Colocar aquí PDFs con texto, DOCX, TXT, MD, XLSX o CSV aprobados para el RAG.
Este alias se mapea a `prestaciones` en `config/knowledge-layout.yaml`.
La carpeta no concede acceso por sí misma. También existe la ruta canónica
`data/knowledge/prestaciones/`; elegir una ubicación por documento.
Ejecutar la ingesta de `docs/INSTALACION_LIMPIA_1.3.0.md` tras añadir documentos.
